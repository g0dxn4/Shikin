# Product screenshots

These are captures of the running Shikin browser app, not design-prototype renders.

| Image                    | Appearance   | Viewport   |
| ------------------------ | ------------ | ---------- |
| `overview-light.webp`    | Native light | 1440 × 660 |
| `transactions-dark.webp` | Native dark  | 1440 × 960 |

Captured on September 20, 2026 for the 1.1 release, using an isolated synthetic dataset. Account names, transactions, balances, investment costs, and manual prices are illustrative—not personal records or live market quotes. No external provider requests were made.

The WebP files are lossless. To refresh them, use current production assets with a separate demo database, wait for startup and data loading to finish, and capture through the app's normal navigation and appearance controls. Do not publish real databases, logs, tokens, or customer information alongside images.

Design studies remain under [`designs/`](../../designs/shikin-native-concept/README.md); they are not substitutes for product screenshots.
