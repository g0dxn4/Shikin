# Support

## Bugs and questions

Use GitHub Issues:

- [Bug report](https://github.com/g0dxn4/Shikin/issues/new?template=bug_report.md)
- [Feature request](https://github.com/g0dxn4/Shikin/issues/new?template=feature_request.md)

Include:

- App **version** (release tag or commit)
- **Platform** (Linux, macOS, or Windows) and architecture if relevant
- **Mode**: desktop app, hosted web (`shikin web` / Tailscale Serve), or CLI/MCP
- Steps that reproduce the problem with **redacted or synthetic** data

Do **not** attach SQLite databases, `.env` files, real backups, unredacted CSV/OFX exports, screenshots of live balances you are not willing to share, or API keys.

## What this project is not

Shikin is not a hosted SaaS and does not provide a built-in chat assistant. Loopback hosted web plus Tailscale Serve is private access to _your_ instance, not a public cloud product.
